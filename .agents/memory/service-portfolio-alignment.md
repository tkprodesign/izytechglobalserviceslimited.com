---
name: Service portfolio alignment
description: The relationship between service-page claims and the company’s published project portfolio
---

Service descriptions and imagery should be grounded in matching published project records whenever the portfolio has relevant work. Avoid using a technically plausible but unrelated project image as evidence for a service.

**Why:** The services page previously paired several categories with unrelated solar, industrial, or team images, which made the company’s offerings look inaccurate even though relevant project records existed.

**How to apply:** When adding or revising a service, first inspect the live project categories, descriptions, service tags, and images. Prefer real project imagery; if a category has no suitable published work, use neutral presentation rather than implying an unrelated project represents that service.
